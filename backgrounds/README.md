# Фоновые фото

Положите сюда фотографии (`.jpg`, `.png`, `.webp`) — на сайте они пойдут фоном слайд-шоу,
по 15 секунд каждая, в случайном порядке. В лобби фото полупрозрачное, во время игры — ещё бледнее.

На GitHub Pages список файлов подтягивается сам (через GitHub API), достаточно загрузить фото
через **Add file → Upload files** в эту папку. Новые фото появятся у игроков в течение ~10 минут.

`list.json` — запасной список на случай, когда GitHub API недоступен (локальный запуск, лимит запросов).
Добавляя фото, по желанию допишите его имя и туда.

Совет: лучше фото не больше 2000 px по длинной стороне и до 1 МБ — быстрее грузятся.
