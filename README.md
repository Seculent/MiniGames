# Игротека

Мини-игры на двоих в браузере: вход через Google, лобби со столами, монетка на первый ход, онлайн-партии, статистика и таблица лидеров.
Хостинг на GitHub Pages, данные в Firebase (бесплатный тариф Spark).

## Запуск: один раз

### 1. Firebase
1. **Authentication → Sign-in method → Google**: включить.
2. **Authentication → Settings → Authorized domains → Add domain**: добавить `ВАШ-ЛОГИН.github.io`.
3. **Firestore Database → Rules**: вставить содержимое файла `firestore.rules` и нажать **Publish**.

### 2. GitHub Pages
1. Создать репозиторий (например, `minigames`) и загрузить в него все файлы из этой папки.
   Через сайт: **Add file → Upload files**, перетащить содержимое папки, **Commit changes**.
2. **Settings → Pages → Build and deployment**: Source — `Deploy from a branch`, Branch — `main`, папка `/ (root)`, **Save**.
3. Через минуту-две сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/minigames/`.

### 3. Админ (для бэкапа сохранений)
1. Войти на сайт, в лобби под «Моими результатами» нажать **копировать** рядом с «Ваш ID».
2. Firebase → **Firestore Database → Data → Start collection**: Collection ID `admins`,
   Document ID — вставить свой ID, поле `role` (string) = `owner`, **Save**.
3. Обновить сайт — в лобби появится блок «Бэкап сохранений»: скачать JSON со статистикой всех игроков
   (только игры против людей) и восстановить её из файла.

## Проверка без интернета
Открыть `index.html?mock=Алиса` в одной вкладке и `index.html?mock=Боб` в другой (через локальный сервер,
например `python3 -m http.server`). Данные хранятся в браузере, Firebase не нужен.

## Как устроено
- `js/app.js` — вход, лобби, страница стола, таблица лидеров.
- `js/tables.js` — места за столом, присутствие (отметка раз в 20 с), монетка, ходы, реванш, техническая победа.
- `js/stats.js` — победы игроков (`stats/{uid}`), из них строится таблица лидеров. Рейтинг считается только по играм против людей.
- Профиль игрока — `profiles/{uid}` (никнейм). При первом входе игрок выбирает ник; в профиле (клик по нику в шапке)
  его можно сменить, посмотреть свой ID и удалить аккаунт вместе со всеми данными.
- `js/registry.js` — список игр в лобби.
- `js/games/colorSquares/` — «Цветные квадраты»: правила (`logic.js`), доска (`view.js`), модуль для лобби (`index.js`).
- `js/games/battleship/` — «Морской бой». Расстановка игрока хранится в `fleets/{uid}` (видит только он сам),
  на выстрелы отвечает браузер защищающегося, в общем состоянии стола — только отпечаток SHA-256 расстановки.
  После боя расстановки раскрываются и сверяются с ответами.

## Как добавить игру (например, «Морской бой»)
1. Создать `js/games/<id>/index.js`, который экспортирует:
   - `newOnlineState(players, first)` — начальное состояние партии (обычный объект, без вложенных массивов);
   - `applyMove(state, seat, move)` — новое состояние или ошибка; при конце партии `state.over = true`, `state.winner` = 0, 1 или -1 (ничья);
   - `mountOnline(root, { onMove })` → объект с `update(state, players, opts)`;
   - `turnText(state, mySeat, names)`, `noteText(note, names)`, `rulesHTML`;
   - по желанию `mountSolo(root, { user, recordSolo })` для игры с ботом (в лобби появится кнопка «Против енота»).
2. Добавить запись в `js/registry.js` (убрать `soon: true`).

Лобби, столы, монетка, статистика и таблица лидеров подхватят игру сами.

## Ограничения
- Результаты записывают браузеры игроков, своего сервера нет. Правила Firestore не дают сесть на чужое живое место
  или писать в чужую статистику, но разбирающийся в коде игрок сможет подделать свой результат. Для своей компании это нормально.
- Бесплатный тариф Firestore: 50 000 чтений и 20 000 записей в сутки. Пара игроков тратит несколько тысяч за вечер.
